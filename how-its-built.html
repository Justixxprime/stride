How this site was built

Plain HTML, Tailwind from a CDN, and hand-written JavaScript. No cart library, no chart library, no framework. Here's what's actually going on under the hood.

0

0

External JS dependencies

0

localStorage, no server

The cart and wishlist

Both are a plain array in localStorage, rewritten and re-rendered from scratch on every change rather than surgically patched. Cart lines are keyed by product + size + color, so the same shoe in two different sizes is genuinely two separate rows.

The fly-to-cart animation

A cloned element is measured with getBoundingClientRect() at its start and end position, then CSS transitions do the actual animating. The cart total updates instantly and independently. The flying clone is a bonus for the eye, not something correctness depends on.

Dark, Light, and System mode

Every color is a CSS variable; Tailwind's color names point at those variables instead of fixed hex values. Toggling .dark on <html> repaints the whole site at once, no per-element dark: classes anywhere.

The custom cursor and page transitions

The cursor ring lags behind the actual pointer on purpose. It eases toward the mouse position every animation frame instead of tracking it exactly, which is what makes it feel alive instead of robotic. Page transitions intercept normal link clicks, play a brief wipe, then navigate. External links and new-tab links are deliberately left alone.

A real bug worth mentioning

Two pages briefly rendered as completely blank. A "fade the page in on load" effect set every page invisible by default and depended on JavaScript to reveal it. But those two pages hadn't loaded that script. Fixed by switching to a pure-CSS @keyframes animation that can't get stuck, since nothing has to remember to turn it back on.
